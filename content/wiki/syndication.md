RSS and Atom feeds of changes

[Shortcuts](https://en.wikipedia.org/wiki/Wikipedia:Shortcut "Wikipedia:Shortcut")

- [WP:RSS](https://en.wikipedia.org/w/index.php?title=Wikipedia:RSS&redirect=no)[WP:RSS](https://en.wikipedia.org/wiki/Wikipedia:RSS "Wikipedia:RSS")
- [WP:XML](https://en.wikipedia.org/w/index.php?title=Wikipedia:XML&redirect=no)[WP:XML](https://en.wikipedia.org/wiki/Wikipedia:XML "Wikipedia:XML")
- [WP:ATOM](https://en.wikipedia.org/w/index.php?title=Wikipedia:ATOM&redirect=no)[WP:ATOM](https://en.wikipedia.org/wiki/Wikipedia:ATOM "Wikipedia:ATOM")
- [WP:SYND](https://en.wikipedia.org/w/index.php?title=Wikipedia:SYND&redirect=no)[WP:SYND](https://en.wikipedia.org/wiki/Wikipedia:SYND "Wikipedia:SYND")

Various aspects of Wikipedia can be monitored with [RSS](https://en.wikipedia.org/wiki/RSS "RSS") or [Atom](https://en.wikipedia.org/wiki/Atom_(standard) "Atom (standard)") feeds to make it easier to keep track of changes.

## Atom (1.0) feeds

\[ [edit source](https://en.wikipedia.org/w/index.php?title=Wikipedia:Syndication&action=edit&section=1 "Edit section's source code: Atom (1.0) feeds")\]

- Changes to any Wikipedia article: go to the article's history page and use the toolbox link labeled "Atom" to subscribe to this feed
- [Recent changes](https://en.wikipedia.org/w/index.php?title=Special:RecentChanges&feed=atom) (alternatively: go to [Special:RecentChanges](https://en.wikipedia.org/wiki/Special:RecentChanges "Special:RecentChanges") and use the toolbox link labeled "Atom" to subscribe to this feed)
- [New pages](https://en.wikipedia.org/w/index.php?title=Special:NewPages&feed=atom) (alternatively: go to [Special:NewPages](https://en.wikipedia.org/wiki/Special:NewPages "Special:NewPages") and use the toolbox link labeled "Atom" to subscribe to this feed)
- User [watchlist](https://en.wikipedia.org/w/api.php?action=feedwatchlist&feedformat=atom) feed; [watchlist with all changes](https://en.wikipedia.org/w/api.php?action=feedwatchlist&feedformat=atom&allrev) (not just the most recent)
- [Contribution](https://en.wikipedia.org/wiki/Special:Contributions "Special:Contributions") pages for a specific user: go to the user's contribution page and use the toolbox link labeled "Atom" to subscribe to this feed

## RSS feeds

\[ [edit source](https://en.wikipedia.org/w/index.php?title=Wikipedia:Syndication&action=edit&section=2 "Edit section's source code: RSS feeds")\]

- Changes to any Wikipedia article: [https://en.wikipedia.org/w/index.php?title=ARTICLENAME&action=history&feed=rss](https://en.wikipedia.org/w/index.php?title=ARTICLENAME&action=history&feed=rss), where ARTICLENAME is the article's name as it appears in your browser's address bar (i.e. with spaces replaced by underscores, etc.)
- [Recent changes](https://en.wikipedia.org/w/index.php?title=Special:RecentChanges&feed=rss)
- [New Pages](https://en.wikipedia.org/w/index.php?title=Special:NewPages&feed=rss)
- User [watchlist](https://en.wikipedia.org/w/api.php?action=feedwatchlist) feed; [watchlist with all changes](https://en.wikipedia.org/w/api.php?action=feedwatchlist&allrev) (not just the most recent)
- User contributions: [http://en.wikipedia.org/w/api.php?action=feedcontributions&user=USERNAME](https://en.wikipedia.org/w/api.php?action=feedcontributions&user=USERNAME), where USERNAME is the name of the user whose contributions should be included in the feed

## Watchlist feed with token

\[ [edit source](https://en.wikipedia.org/w/index.php?title=Wikipedia:Syndication&action=edit&section=3 "Edit section's source code: Watchlist feed with token")\]

You can set up an RSS or Atom feed of your watchlist that is accessible even when logged out:[\[1\]](https://en.wikipedia.org/wiki/Wikipedia:Syndication#cite_note-wikipedia-watchlist-rss-1)

1. Go to [Special:Preferences](https://en.wikipedia.org/wiki/Special:Preferences "Special:Preferences")
2. Click the "Watchlist" tab
3. Go to the "Token" section and click the "Manage tokens" button
4. On this "Reset tokens" page, copy and paste the randomly-generated value token value for the next step[\[2\]](https://en.wikipedia.org/wiki/Wikipedia:Syndication#cite_note-2)
5. Your watchlist RSS feed can be found at `https://en.wikipedia.org/w/api.php?action=feedwatchlist&wlowner=USERNAME&wltoken=TOKEN`, where USERNAME is your username without the _User:_ prefix and TOKEN is the watchlist token you copied from your preferences. If you would prefer an Atom feed rather than an RSS one, add "&feedformat=atom" to the Link of your feed.
6. Similar to your watchlist preferences, the feed of your watchlist can be customized by adding different parameters to the link of your feed, see [documentation on Mediawiki](https://www.mediawiki.org/wiki/API:Watchlist_feed "mw:API:Watchlist feed"). e.g. `&hours=72&wlexcludeuser=USERNAME` to display the maximum length and to exclude your own changes.

## XML exports

\[ [edit source](https://en.wikipedia.org/w/index.php?title=Wikipedia:Syndication&action=edit&section=4 "Edit section's source code: XML exports")\]

You can export the contents of a particular article or set of articles in XML format via the [Special:Export](https://en.wikipedia.org/wiki/Special:Export "Special:Export") page. This special page allows exporting the history of the page as well (up to 1000 revisions). Test out the full-history export on a page with a short history, to make sure you know what you are getting.
