# Hello, world!

(Redirected from [Hello world](https://esolangs.org/w/index.php?title=Hello_world&redirect=no "Hello world"))

_Not to be confused with [Hello,world!](https://esolangs.org/wiki/Hello,world! "Hello,world!")._

A **"Hello, world!" program** is a trivial program which outputs a static string of text[note 1](https://esolangs.org/wiki/Hello,_world!#cite_note-1), usually

Hello, world!

This program is often the first one written in a new [esoteric programming language](https://esolangs.org/wiki/Esoteric_programming_language "Esoteric programming language"), to demonstrate output. It is a [popular problem](https://esolangs.org/wiki/Popular_problem "Popular problem").

The program comes from the first example program in the classic K&R C manual. Note that the K&R version was in all lowercase and lacked an exclamation mark.
