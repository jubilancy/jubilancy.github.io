# Claude Pro — Benefits & Features

> **Price:** $20/month · $17/month billed annually ($204/year, ~15% savings)

---

## Usage & Access
- **5× more usage per session** than the free plan (rolling 5-hour window; resets every 5 hours)
- Weekly usage limit that applies across all models (reset day is fixed per account — visible in Settings > Usage)
- **Priority access** to Claude during high-traffic periods — fewer slowdowns or "capacity exceeded" messages
- **Usage credits** add-on: optionally purchase additional capacity beyond plan limits without upgrading plans
- Access to **all Claude models**, including Claude Sonnet 4.6 and Claude Opus 4.6 (and future model releases)

---

## AI Features
- **Extended Thinking / Reasoning Mode** — Claude pauses to reason through multi-step logic before responding (exclusive to paid tiers)
- **Web search** — Claude can search the web for up-to-date information inline during conversations
- **File uploads** — attach PDFs, spreadsheets, code files, images, and other documents (larger limits than free tier)
- **200K+ token context window** — handle very long documents and multi-file analysis in a single conversation
- **Image analysis** — interpret and describe images, screenshots, diagrams, and more

---

## Projects & Memory
- **Unlimited Projects** — organize conversations by topic with shared context and custom instructions
- Upload reference documents to Projects that persist across all chats within that project
- Set project-specific instructions, tone, and behavior that apply to every conversation
- **Memory** — Claude can generate and store memories about you to personalize responses over time
- Conversations organized, searchable, and accessible within projects

---

## Productivity Tools & Integrations
- **Claude Code** — agentic coding assistant in the terminal, VS Code, JetBrains, and desktop app
- **Cowork** — desktop tool to hand off multi-step file and task management to Claude
- **Google Workspace integration** — Claude can access Gmail, Google Drive, Google Docs, and Sheets
- **Remote MCP connectors** — connect Claude to external apps and services via Model Context Protocol
- **Claude in Excel** — Claude integrated into Microsoft Excel for formulas, data, and analysis
- **Claude in PowerPoint** — Claude integrated into PowerPoint for building and editing slides
- **Code execution and file creation** — run Python code, analyze data, and create downloadable files
- **Artifacts** — interactive, visual outputs (charts, apps, documents) created inline in chat

---

## Privacy & Early Access
- **Opt out of conversation training data** — Pro users can disable use of their conversations for model training (unlike free tier)
- **Early access to new features** before they roll out to free users
- Access to beta products and features as they become available

---

## Pricing Notes
- Does **not** include API access to Claude via the Anthropic Console — API usage is billed separately
- Annual plan saves ~$36/year; no free trial offered; cancel anytime on monthly plan
- Pro sits between the free tier and Claude Max ($100–$200/month for 5×–20× more usage)

# Perplexity Pro — Benefits & Features

---

## Search & Research
- **Unlimited Pro Searches** — multi-step deep research mode that queries 20–30+ sources per question, cross-references facts, and synthesizes a comprehensive cited answer (free tier limited to 5/day)
- **Unlimited Reasoning Search** — for complex multi-step analytical queries
- **Extended Deep Research (Perplexity Research mode)** — auto-selects the optimal AI model combination for in-depth research reports without manual model selection
- **10× more citations per answer** than the free tier for greater reference depth and transparency
- Real-time web search on every query — answers are always current, not limited to training data
- Access to **premium data sources** and publisher partnerships (2,400+ publishers as of Q1 2026)
