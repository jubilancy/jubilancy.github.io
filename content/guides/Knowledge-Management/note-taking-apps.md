# Free Browser-Based Note-Taking Apps Comparison

A comprehensive guide to free, browser-accessible note-taking systems with import/export capabilities, organized by performance characteristics.

## Overview

All listed applications are:
- **Free** to use
- **Browser-accessible** (web-based or progressive web apps)
- **Import/Export capable** with multiple format support
- Organized from **lightweight** (Notesnook-like) to **heavy** (Notion-like)

---

## Very Lightweight Options

### Standard Notes

**Similar to:** Simplenote (minimalist privacy-focused note-taking)

**Browser Access:** Full web app at standardnotes.com

**Import/Export:**
- Import: Evernote (ENEX), Google Keep, plaintext, Markdown
- Export: Individual notes as .txt files, comprehensive export tools

**Free Features:** Basic note-taking with encrypted storage (some organizational features require premium)

**Performance:** ⚡⚡⚡⚡⚡ Very lightweight and fast

---

### Simplenote

**Similar to:** Apple Notes (clean, straightforward interface)

**Browser Access:** Full web browser access with sync

**Import/Export:**
- Import: Evernote, other Simplenote accounts, plain text files
- Export: .json and .txt formats

**Free Features:** Completely free with unlimited notes, tags, and cross-device sync

**Performance:** ⚡⚡⚡⚡⚡ Extremely lightweight

---

### TiddlyWiki

**Similar to:** Personal wiki (highly customizable, interconnected notes)

**Browser Access:** Runs entirely in browser as a single HTML file

**Import/Export:**
- Import: Various text formats
- Export: Built-in export capabilities

**Free Features:** Completely free with unlimited customization and advanced linking features

**Performance:** ⚡⚡⚡⚡⚡ Exceptionally lightweight (single file)

---

## Lightweight-to-Medium Options

### Logseq

**Similar to:** Obsidian (block-based note-taking with graph view)

**Browser Access:** Web version available at test.logseq.com

**Import/Export:**
- Import/Export: Markdown files, various text formats (file-based)
- Web clipper extension available

**Free Features:** Completely free and open-source with all advanced features included

**Performance:** ⚡⚡⚡⚡ Lightweight to medium

**Best For:** Users who want graph visualization and bidirectional linking

---

### Joplin

**Similar to:** Obsidian (markdown-focused with strong organization)

**Browser Access:** Primarily desktop-focused but can be self-hosted for web access

**Import/Export:**
- Import: Evernote and other sources
- Export: Full export capabilities, web clipper extension
- Formats: Markdown, ENEX, JEX, PDF

**Free Features:** Open-source with all features free, end-to-end encryption available

**Performance:** ⚡⚡⚡⚡ Medium-light

**Best For:** Users wanting Obsidian-like features with strong encryption

---

### Workflowy

**Similar to:** Dynalist (hierarchical bullet-point organization)

**Browser Access:** Fully browser-based application

**Import/Export:**
- Import: Text sources
- Export: Markdown, OPML, and formatted text

**Free Features:** Free tier with limited monthly items, export functionality available

**Performance:** ⚡⚡⚡⚡ Medium

**Best For:** Outline-based organization and task management

---

## Medium Weight Options

### Notesnook (Your Baseline)

**Similar to:** Privacy-focused Notion (modern interface with strong security)

**Browser Access:** Full web application

**Import/Export:**
- Multiple formats supported
- Encryption capabilities built-in

**Free Features:** 50MB monthly storage with core features

**Performance:** ⚡⚡⚡ Medium

**Best For:** Privacy-conscious users wanting modern features

---

### AppFlowy

**Similar to:** Notion (block-based workspace with databases)

**Browser Access:** Available at appflowy.com with full web functionality

**Import/Export:**
- Open-source with various export formats
- Can be self-hosted

**Free Features:** Open-source with all features free, including AI capabilities and collaboration

**Performance:** ⚡⚡⚡ Medium (lighter than Notion)

**Best For:** Users wanting Notion-like features without proprietary lock-in

---

### Cryptee

**Similar to:** Encrypted Google Docs (privacy-focused document editor)

**Browser Access:** Progressive Web App that works entirely in browser

**Import/Export:**
- Import: Evernote, Word documents, PDFs
- Export: PDF, HTML, Markdown formats

**Free Features:** 100MB free cloud storage with strong encryption and offline capabilities

**Free Plan Limits:**
- 100MB total cloud storage
- 500MB max file size per upload
- Suitable for text and document notes (not photo-focused)

**Performance:** ⚡⚡⚡ Medium

**Best For:** Encrypted document storage without photo capabilities

---

### CryptPad

**Similar to:** Collaborative Google Docs with end-to-end encryption

**Browser Access:** Fully browser-based collaborative platform

**Import/Export:**
- Various document types supported
- Export capabilities for multiple formats

**Free Features:** Free tier with collaborative editing (storage may be limited)

**Performance:** ⚡⚡⚡ Medium (heavier due to real-time collaboration)

**Best For:** Collaborative note-taking with encryption

---

## Medium-to-Heavy Options

### RemNote

**Similar to:** Roam Research (interconnected notes with spaced repetition)

**Browser Access:** Web application available

**Import/Export:**
- Various import/export options
- Strong academic and research focus

**Free Features:** Free tier with core features (premium unlocks advanced capabilities)

**Performance:** ⚡⚡ Medium-heavy

**Best For:** Academic note-taking and knowledge management

---

### Google Keep

**Similar to:** Sticky notes app (quick capture with visual organization)

**Browser Access:** Full web interface at keep.google.com

**Import/Export:**
- Limited export options via Google Takeout
- Can import via Standard Notes converter

**Free Features:** Free with Google account, 15GB shared across Google services

**Performance:** ⚡⚡ Medium-heavy

**Best For:** Quick capture and visual note organization

---

### Microsoft OneNote

**Similar to:** Digital notebook (freeform note-taking with rich media)

**Browser Access:** Full web version available

**Import/Export:**
- Good import/export capabilities
- Various format support

**Free Features:** Generous free tier with 5GB storage

**Performance:** ⚡⚡ Medium-heavy

**Best For:** Rich media note-taking with Microsoft ecosystem integration

---

## Heavy Options

### Notion

**Similar to:** All-in-one workspace (databases, wikis, project management combined)

**Browser Access:** Primary interface is web-based

**Import/Export:**
- Comprehensive import options
- Limited export capabilities

**Free Features:** Feature-rich free plan for personal use

**Performance:** ⚡ Heavy (feature-rich but slower)

**Best For:** Complex workspace management, databases, and project coordination

## Recommendations by Use Case

**For Minimal, Private Note-Taking:**
→ **Standard Notes** or **Simplenote**
- Ultra-lightweight
- Strong privacy features
- Excellent import/export

**For Wiki-Style Organization:**
→ **TiddlyWiki** or **Logseq**
- Interconnected notes
- Graph visualization
- Offline-capable

**For Markdown Enthusiasts:**
→ **Joplin**
- Strong markdown support
- Evernote import
- End-to-end encryption

**For Task/Outline Management:**
→ **Workflowy**
- Hierarchical organization
- Clean interface
- Export to OPML

**For Encrypted Document Storage:**
→ **Cryptee**
- 100MB free tier
- Rich document editing
- Strong encryption

**For Collaborative Notes:**
→ **CryptPad**
- Real-time collaboration
- End-to-end encryption
- Multiple document types

**For Notion-Like Features (Lighter):**
→ **AppFlowy**
- Open-source alternative
- Database and workspace features
- No proprietary lock-in

**For Academic Research:**
→ **RemNote**
- Spaced repetition
- Knowledge management
- Academic focus

**For Complex Workspaces:**
→ **Notion**
- Most powerful features
- Extensive customization
- Heaviest performance cost

## Key Takeaways

1. **For lightweight users:** Standard Notes, Simplenote, or TiddlyWiki offer the best performance
2. **For balanced features:** Logseq, Joplin, or Notesnook provide good middle ground
3. **For collaboration:** CryptPad or AppFlowy are your best options
4. **For privacy:** Notesnook, Standard Notes, Cryptee, or Joplin with encryption enabled
5. **All listed apps** support import/export and browser access as required
