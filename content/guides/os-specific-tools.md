### ✅ Summary: Best Free Tools by Use Case

– **For full website downloads (images, videos, fonts):** HTTrack, wget, SiteSucker  
– **For bulk image downloads via browser:** Image Downloader, DownThemAll!, Save Image As...  
– **For scraping media from complex sites:** Octoparse, ParseHub, [Webscraper.io](http://webscraper.io/)  
– **For local media organizing after download:** digiKam, TagSpaces, MediaMate  
– **For bookmark-style organization (not files):** [Raindrop.io](http://raindrop.io/)  
– **For Safari integration (basic):** Download All Images, Save Image As...  
– **For Safari integration (advanced):** Only paid [Eagle.app](http://eagle.app/) offers full features
