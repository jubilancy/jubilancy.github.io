# safari services

- **Add to Music as a Spoken Track**: Turns selected text into an audio track using text-to-speech, then adds it to your Music app library.
- **Convert Text to Simplified Chinese**: Instantly changes highlighted text into Simplified Chinese characters.
- **Convert Text to Traditional Chinese**: Instantly changes highlighted text into Traditional Chinese characters.
- **Create Service**: Opens Automator to build a new macOS Service (custom contextual workflow).
- **Create Workflow**: Opens Automator for creating a workflow, similar to Services but with broader automation use.
- **Get Result of AppleScript**: Runs an AppleScript on the selected text or item and shows the output.
- **Make New AppleScript**: Opens the AppleScript Editor with a new script window.
- **Make New Sticky Note**: Creates a new Sticky Note containing the selected text.
- **New TextEdit Window Containing Selection**: Opens TextEdit with the highlighted text inside a new document.
- **Open**: Opens the selected file, link, or text snippet using the default app.
- **Open man Page in Terminal**: Sends the selected Unix command to Terminal and opens its manual (man) page.
- **Run as AppleScript**: Executes the highlighted text as if it were AppleScript code.
- **Search man Page Index in Terminal**: Looks up the selected word or command in the Unix manual index via Terminal.
- **Show in Finder**: Reveals the selected file or item’s location in Finder.
- **Show Info in Finder**: Opens the “Get Info” window in Finder for the selected file or item.
- **Spotlight**: Searches for the selected text or item using Spotlight search.
- **Summarize**: Generates a condensed version of the highlighted text using macOS’s built-in summarizer.

# Keyboard Shortcuts

- **Launchpad & Dock**: Shortcuts related to opening Launchpad, showing/hiding the Dock, and navigating apps.
- **Display**: Shortcuts for adjusting brightness, screen resolution, or display settings.
- **Mission Control**: Shortcuts for managing windows, desktops (Spaces), and app overviews.
- **Keyboard**: General shortcuts for system-level key functions and customization.
- **Input Sources**: Shortcuts for switching between different language keyboards or input methods.
- **Screenshots**: Shortcuts to capture the entire screen, a window, or a selected portion.
- **Presenter Overlay**: Shortcuts for showing presenter tools or overlays during screen sharing or presentations.
- **Services**: Shortcuts for quickly accessing macOS Services, such as text transformations or automation workflows.
- **Spotlight**: Shortcuts for opening and searching with Spotlight.
- **Accessibility**: Shortcuts for enabling and managing accessibility features (e.g., VoiceOver, Zoom, etc.).
- **App Shortcuts**: Custom keyboard shortcuts you assign to menu items in specific apps.
- **Function Keys**: Settings for how the function keys (F1–F12) behave — as standard keys or special features.
- **Modifier Keys**: Settings to customize the behavior of Command, Option, Control, and Caps Lock keys.

## Utilities

- **Activity Monitor**: Tracks system processes, memory, CPU, and energy usage.
- **AirPort Utility**: Configures and manages Apple’s AirPort Wi-Fi base stations.
- **Audio MIDI Setup**: Configures audio devices, speakers, and MIDI instruments.
- **Bluetooth File Exchange**: Transfers files between your Mac and Bluetooth devices.
- **Boot Camp Assistant**: Helps install and run Windows on a Mac.
- **ColorSync Utility**: Manages color profiles and calibrates displays.
- **Console**: Displays system logs and diagnostic messages.
- **Digital Color Meter**: Measures the RGB values of any pixel on screen.
- **Disk Utility**: Manages disks, partitions, and storage devices.
- **Feedback Assistant**: Used to send bug reports and feedback to Apple.
- **Grapher**: Creates 2D and 3D graphs for equations and data.
- **Keychain Access**: Stores and manages passwords, certificates, and secure notes.
- **Migration Assistant**: Transfers data from another Mac or Windows PC.
- **Print Center**: Manages printers and print jobs.
- **Screen Sharing**: Connects to and controls another Mac remotely.
- **Screenshot**: Captures part or all of your screen (successor to Grab).
- **Script Editor**: Edits and runs AppleScript and JavaScript for automation.
- **System Information**: Displays detailed hardware and software information about your Mac.
- **Terminal**: Command-line interface for running Unix commands.
- **VoiceOver Utility**: Configures settings for VoiceOver, macOS’s built-in screen reader.
