**TL;DR**: macOS supports a vast array of system-wide, application-specific, and custom keyboard shortcuts. You can use standard modifier keys (⌘, ⌥, ⌃, ⇧) to trigger everything from window management to automated scripts.

---

## **1. Common System Shortcuts**

These work in almost every app on **[macOS](https://www.google.com/search?q=https://www.apple.com/macos/)**:

- **⌘ + C / V / X**: Copy, Paste, Cut.
    
- **⌘ + Z**: Undo (and **⇧ + ⌘ + Z** for Redo).
    
- **⌘ + Space**: Open **[Spotlight Search](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/spotlight-mchlp1008/mac)**.
    
- **⌘ + Tab**: Switch between open applications.
    
- **⌘ + W**: Close the current window.
    
- **⌘ + Q**: Quit the current application.
    
- **Option + ⌘ + Esc**: Force Quit an application.
    

---

## **2. Screenshot & Screen Recording**

- **⇧ + ⌘ + 3**: Capture the entire screen.
    
- **⇧ + ⌘ + 4**: Capture a selected portion of the screen.
    
- **⇧ + ⌘ + 5**: Open the **[Screenshot/Screen Recording](https://support.apple.com/guide/mac-help/take-a-screenshot-mh26782/mac)** interface.
    

---

## **3. Advanced Customization**

You can create your own shortcuts for almost any menu item or automation:

- **App Shortcuts**: In **System Settings > Keyboard > Keyboard Shortcuts > App Shortcuts**, you can map a key combo to any existing menu command (like "Export as PDF...").
    
- **Services / Quick Actions**: As we did with your file-creation script, these appear under **Services** and can be assigned keys in **Keyboard > Keyboard Shortcuts > Services**.
    
- **Shortcuts App**: Use the **[Shortcuts app](https://support.apple.com/guide/shortcuts-mac/welcome/mac)** to build complex multi-step workflows (like resizing images or sending automated emails) and trigger them via the Menu Bar or a hotkey.
    

---

## **4. Finder-Specific Shortcuts**

- **⌘ + N**: Open a new Finder window.
    
- **⇧ + ⌘ + N**: Create a new folder.
    
- **⌘ + Delete**: Move selected item to the Trash.
    
- **⇧ + ⌘ + . (Period)**: Show or hide hidden files in a folder.
    
- **Spacebar**: **[Quick Look](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/view-and-edit-files-with-quick-look-mh14119/mac)** (preview a file without opening its app).
    

---

## **5. Modifier Key Symbols**

When looking at macOS menus, these symbols represent the keys on your keyboard:

- **⌘**: Command (Cmd)
    
- **⌥**: Option (Alt)
    
- **⌃**: Control (Ctrl)
    
- **⇧**: Shift
    
- **⇪**: Caps Lock
    
- **fn**: Function (or the Globe key)

**TL;DR**: macOS recognizes **seven** primary modifier keys, which can be combined in various configurations to trigger system functions or characters.

---

## **Standard Modifier Keys**

These are the primary keys used in keyboard shortcuts and menu navigation:

- **[Command](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/what-are-the-symbols-used-in-macos-menus-cpmh0011/mac) (⌘)**: The main modifier for system and application commands (e.g., Copy, Paste).
    
- **[Option / Alt](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/what-are-the-symbols-used-in-macos-menus-cpmh0011/mac) (⌥)**: Used for typing special characters, alternative menu actions, and navigation shortcuts.
    
- **[Control](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/what-are-the-symbols-used-in-macos-menus-cpmh0011/mac) (⌃)**: Used for contextual menus (right-clicking) and specialized system commands.
    
- **[Shift](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/what-are-the-symbols-used-in-macos-menus-cpmh0011/mac) (⇧)**: Used for capitalization and secondary functions within existing shortcuts.
    

---

## **Secondary & Special Modifiers**

These keys modify behavior but are less frequently used in traditional "Cmd+Key" shortcuts:

- **[Fn / Globe](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/use-the-fn-or-globe-key-on-your-mac-mchlb969247d/mac)**: Toggles between function keys (F1-F12) and media controls; on modern Macs, it opens the Emoji picker or switches input languages.
    
- **[Caps Lock](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/what-are-the-symbols-used-in-macos-menus-cpmh0011/mac) (⇪)**: While primarily for text, it can be remapped (e.g., to "Hyper" keys) using third-party software.
    
- **[Escape](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/use-the-esc-key-on-your-mac-mchlp2262/mac) (⎋)**: Acts as a modifier in certain developer environments (like Vim) or system shortcuts (e.g., Force Quit).
    

---

## **The "Hyper" Key (Third-Party)**

- **Hyper Key**: A virtual modifier created by apps like **[Karabiner-Elements](https://karabiner-elements.pqrs.org/)**. It maps a single key (usually Caps Lock) to act as **⌘ + ⌥ + ⌃ + ⇧** simultaneously, allowing you to create custom shortcuts that never conflict with system defaults.
    

---

## **Common Combinations**

Modifiers are often stacked to provide deeper layers of functionality:

|**Combination**|**Common Use Case**|
|---|---|
|**⌘ + ⇧**|Reverse an action (e.g., Redo) or "Save As"|
|**⌘ + ⌥**|Advanced actions (e.g., Empty Trash without prompt)|
|**⌘ + ⌃**|Window management or full-screen toggles|
|**⌘ + ⌥ + ⇧**|Deep system resets (e.g., Resetting app preferences)|

## **Why "zzz" Doesn't Work Directly**

- **Collision with Typing**: If you assigned `z` to a shortcut, you would never be able to type the letter "z" in a document or search bar without triggering your script.
    
- **macOS Requirements**: The **[Keyboard Shortcuts](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/create-keyboard-shortcuts-for-apps-mchlp2271/mac)** pane in System Settings will not register a keypress unless a modifier is held down first.
    

---

## **Alternative Solutions**

### **1. Use a Modifier (The Standard Way)**

To use "z" as your trigger, you would need to combine it with modifiers.

- **Example**: `⌘ + ⌥ + Z` or `⌃ + ⌥ + ⌘ + Z`.
    
- This keeps your hands near the "z" key while ensuring the command is intentional.
    

### **2. Text Replacement (The "Fragment" Way)**

If you want to type "zzz" and have it _do_ something, you can use **[Text Replacements](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/replace-text-and-punctuation-in-documents-on-mac-mchlp2240/mac)**:

- Go to **System Settings > Keyboard > Text Replacements**.
    
- Set **Replace** to `zzz` and **With** to a specific string.
    
- _Note_: This only replaces text; it cannot run your Automator script.
    

### **3. Third-Party "Hotstrings" (The Power User Way)**

If you are determined to use "zzz" to trigger a script without modifiers, you need a third-party automation tool like **[BetterTouchTool](https://folivora.ai/)** or **[Keyboard Maestro](https://www.keyboardmaestro.com/)**.

- These apps can listen for "Key Sequences" (typing specific letters in a row).
    
- You can configure them to watch for `z` → `z` → `z` and then execute your shell script automatically.

For the **[Automator](https://support.apple.com/guide/automator/welcome/mac)** action we built, the most stable and "native" approach is assigning:

- **`⌃ + ⌥ + ⌘ + Z`** (Control + Option + Command + Z)
    
- This is a "safe" shortcut that is unlikely to conflict with any existing app's built-in shortcuts.

## **1. System-Wide Shortcuts (Native)**

To see the shortcuts built into macOS (Screenshots, Spotlight, Mission Control, and your custom **[Automator](https://support.apple.com/guide/automator/welcome/mac)** actions):

- Open **[System Settings](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/change-system-settings-mchlp1053/mac)**.
    
- Navigate to **Keyboard > Keyboard Shortcuts**.
    
- **Check the "Services" category**: This is where your custom "Create File from Highlight" shortcut will be listed under the "Text" sub-section.
    

---

## **2. Active App Shortcuts (Visual)**

If you want to see all shortcuts for the app you are currently using (e.g., **[Figma](https://www.figma.com/)**, Chrome, or Terminal):

- **Third-Party Tool**: **[CheatSheet](https://www.mediaatelier.com/CheatSheet/)** (Free) or **[KeyCue](https://www.ergonis.com/products/keycue/)**.
    
- **How it works**: You hold down the **Command (⌘)** key for two seconds, and a transparent overlay appears listing every keyboard shortcut available in your active window.

## **3. Custom App Shortcuts**

If you have created specific shortcuts for menu items (like "Export as PNG"):

- Go to **System Settings > Keyboard > Keyboard Shortcuts > App Shortcuts**.
    
- This lists every manual override you have created for specific software.

## **4. Advanced Terminal List (Read-Only)**

For a technical look at your custom global key bindings, you can read the **[plist](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/AboutInformationPropertyListFiles.html)** file where macOS stores them. ### **Which area are you most concerned about overlapping with?**

Knowing if you use a specific launcher (like Raycast) or design tool (like Figma) can help narrow down the "safe" keys for your new file-creation script.

**TL;DR**: macOS does not provide a single text file or terminal command to export every shortcut at once. However, you can view the specific categories you listed in **System Settings** or use specific **Terminal** commands to extract data for **Services** and **Custom App Shortcuts**.

**TL;DR**: Run the following **[Zsh](https://www.zsh.org/)** command in your **[Terminal](https://support.apple.com/guide/terminal/welcome/mac)** to generate a formatted `SettingsExport.md` file on your Desktop.

Bash

```bash
{
  echo "# macOS Settings Export - $(date)"
  echo "---"
  
  echo "## Keyboard Settings"
  echo "\`\`\`"
  defaults read com.apple.keyboard 2>/dev/null || echo "No custom keyboard defaults found."
  echo "\`\`\`"
  
  echo "## Services & Shortcuts"
  echo "\`\`\`"
  defaults read pbs 2>/dev/null || echo "No services data found."
  echo "\`\`\`"
  
  echo "## Spotlight Configuration"
  echo "\`\`\`"
  defaults read com.apple.spotlight 2>/dev/null || echo "No spotlight defaults found."
  echo "\`\`\`"
  
  echo "## Desktop & Dock"
  echo "\`\`\`"
  defaults read com.apple.dock 2>/dev/null || echo "No dock defaults found."
  echo "\`\`\`"
  
  echo "## Trackpad & Multitouch"
  echo "\`\`\`"
  defaults read com.apple.AppleMultitouchTrackpad 2>/dev/null || echo "No trackpad defaults found."
  echo "\`\`\`"
} > ~/Desktop/SettingsExport.md
```

---

### **How this works**

- **Braces `{ ... }`**: Groups all commands together so the output can be redirected into a single file at once.
    
- **Redirection `>`**: Creates the `SettingsExport.md` file on your **[Desktop](https://www.google.com/search?q=https://support.apple.com/guide/mac-help/mchlp2304/mac)**. If the file already exists, this will overwrite it.
    
- **Error Handling `2>/dev/null`**: This prevents the "domain does not exist" error message from cluttering your Markdown file if you haven't changed the factory defaults for a specific category.
    
- **Markdown Formatting**: Wraps each output in code blocks (//developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/AboutInformationPropertyListFiles.html)** data.
