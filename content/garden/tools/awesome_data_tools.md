# Awesome Indie & Research Data Tools

A curated list of free, browser-based tools for data management, workspace persistence, and creative projects.

## Cloud Data Workspaces (Jupyter-like)
These platforms provide persistent cloud workspaces for CSV, JSON, and research data.

* [Kaggle Notebooks](https://www.kaggle.com/code) - Industry standard for persistent data science workspaces.
* [Deepnote](https://deepnote.com) - Best-in-class UI for notebook-style research and data management.
* [JetBrains Datalore](https://datalore.jetbrains.com) - Professional IDE-like workspace with excellent data visualization.
* [Google Colab](https://colab.research.google.com) - Ubiquitous, fast, and integrates seamlessly with Google Drive.
* [CoCalc](https://cocalc.com) - The ultimate academic environment for math, LaTeX, and data science.
* [Noteable](https://noteable.io) - Collaborative data notebooks with visual explorations.
* [ObservableHQ](https://observablehq.com) - Interactive notebooks for data visualization and data-driven documents.
* [Hex](https://hex.tech) - Modern data workspace that turns notebooks into interactive apps.
* [Binder](https://mybinder.org) - Turns a GitHub repository into an interactive notebook environment.
* [Ploomber Cloud](https://ploomber.io) - Simplifies data pipeline development in the browser.

## Landing Page & Microsite Builders
Platforms for indie creators to launch sites quickly.

* [Carrd](https://carrd.co) - The gold standard for simple, one-page sites.
* [Typedream](https://typedream.com) - Minimalist, Notion-inspired site builder.
* [Unicorn Platform](https://unicornplatform.com) - AI-assisted builder designed for startup landing pages.
* [Dorik](https://dorik.com) - Powerful no-code CMS for indie makers.
* [Framer](https://framer.com) - Design-first builder for high-fidelity portfolios.
* [Popsy](https://popsy.co) - Create websites from Notion pages.
* [ConvertKit Landing Pages](https://convertkit.com) - Optimized for creator growth and email capture.
* [Milkshake](https://milkshake.app) - Mobile-first website builder for Instagram link-in-bio.
* [Super](https://super.so) - High-performance sites built on Notion.
* [Site123](https://site123.com) - Simple, user-friendly builder for small business pages.

## Browser-Based Media Editors
Free tools for editing images and videos directly in your browser.

* [Clipchamp](https://clipchamp.com) - High-quality, watermark-free video editor.
* [Photopea](https://www.photopea.com) - Advanced, Photoshop-like image manipulation.
* [CapCut](https://www.capcut.com) - Trend-focused video editor with robust AI features.
* [Adobe Express](https://www.adobe.com/express/) - Comprehensive design tool for social graphics.
* [Pixlr](https://pixlr.com) - Quick, browser-based photo editor with AI tools.
* [BeFunky](https://befunky.com) - Easy-to-use photo editor and collage maker.
* [Canva](https://canva.com) - All-in-one graphic design platform.
* [Flixier](https://flixier.com) - Cloud-based video editor with real-time rendering.
* [Kapwing](https://kapwing.com) - Quick video editing and meme maker.
* [Vectr](https://vectr.com) - Simple, browser-based vector graphics editor.

## Data Utilities & Visualization
Tools for CSV, JSON management, and mapping data.

* [Datablist](https://datablist.com) - Great for data cleaning and filtering.
* [CSVJSON](https://csvjson.com) - Quick conversion and editing for developers.
* [RAWGraphs](https://rawgraphs.io) - Open-source tool to create custom visualizations from CSV/JSON.
* [Datawrapper](https://datawrapper.de) - Create interactive charts and maps without coding.
* [JSONBin.io](https://jsonbin.io) - Service to host and share JSON data files.
* [CSV-to-JSON.com](https://csv-to-json.com) - Straightforward conversion tool.
* [TableConvert](https://tableconvert.com) - Convert and format tables between multiple formats.
* [Mr. Data Converter](https://shancarter.github.io/mr-data-converter/) - Converts Excel data into JSON, HTML, and XML.
