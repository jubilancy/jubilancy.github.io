# Drop cap initials

The 21 initials (A B C D E F G H I K L M N P Q R S T U V Y) are cut from a single vector file,
[Ornamental Alphabet - 16th Century.svg](https://commons.wikimedia.org/wiki/File:Ornamental_Alphabet_-_16th_Century.svg),
on Wikimedia Commons.

- Original artwork: F. Delamotte, from *Ornamental Alphabets, Ancient and Mediaeval* (1879)
- Vectorized and restored by JovanCormac
- Marked as public domain (Creative Commons Public Domain Mark 1.0) on the file page

Each letter is the original's shapes for one framed cell, exported as its own SVG with a parchment
background rectangle added and coordinates rounded to one decimal place. The file has no J, O, W, X or Z.
